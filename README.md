# Невинные сладости

Форма обращений о десертах на заказ. После подтверждения в Telegram владелец и клиент могут вести переписку по номеру обращения.

Страница размещается в Cloudflare Pages. Публикуйте только папку public, без команды сборки. База и обработчики находятся в отдельном проекте Supabase. В public/config.js указываются только адрес create-application и имя бота. В Supabase SITE_URL должен соответствовать рабочему адресу страницы.

## Проверки и обновление

Для Node.js 24: npm ci, npm run check, npm test. Команда npm run preview открывает локальную страницу на 127.0.0.1:8788. npm run bundle готовит файлы для редактора Supabase в .local/dashboard.

Обновления страницы публикуйте в Pages. Изменения функций разворачивайте в Supabase отдельно. Миграции применяйте последовательно из supabase/migrations. Локальный .local/secrets.env и настройки секретов Supabase не публикуются.

## Бот и доставка

Владелец открывает /requests. Клиент использует /my. Чтобы написать по обращению, ответьте на соответствующую подсказку бота. /id показывает собственный Telegram ID. /retry у владельца показывает неудачные отправки и позволяет повторить их.

При первичной настройке используйте временную setup-telegram. Команда node scripts/owner.mjs status читает состояние webhook через Supabase. Действия register и test соответственно регистрируют webhook и отправляют служебное сообщение владельцу. После проверки удалите временную функцию из Supabase. Исходный код оставьте в репозитории.

После публикации пройдите контрольное обращение и проверьте ответ, историю и статус. Бесплатные планы имеют квоты. Supabase может приостановить неактивный проект. При сбое между отправкой в Telegram и записью результата возможен повтор сообщения.
